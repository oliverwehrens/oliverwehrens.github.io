Open Settings with ⌘, or “Settings…” in the menubar menu. Settings are stored in settings.json in the data folder. You can edit the file by hand: unknown keys are ignored and missing keys use their defaults.

#Activity

A window must stay in front for the “Record a window after” time before it shows up in the timeline. Shorter visits count toward the next window. Lock, sleep, idle and pause end the current span.

#Screenshots

SettingDefaultChoices
Capture every5 min1, 2, 5, 10, 15, 30 min
Longest image edge1500 px1000, 1280, 1500, 1920, 2560 px
Capture active window onlyon

With “Capture active window only” on, a screenshot shows the front window. It shows the whole display instead when no window is open, when Daily Recall is in front, or when the window covers less than 10% of its display. No screenshots are taken while idle, locked, asleep or paused.

#Marked Moments

⌃⌥⌘M captures the front window and asks for a note. It works while paused. The model analyses it with prompt 3, and the day summary always includes it.

“About me” and the six prompts, with import and export. See prompts.

#Private

Rules that keep activity away from the model. A rule matches an app, a domain (including its subdomains), text in the window title, or a combination. With several set, a window must match all of them.

Matching activity:

  • still counts in the overview, with a lock
  • is left out of the summary log and the time per app the model sees
  • is not analysed: periodic screenshots of a private window are skipped
  • is left out of search results and meeting digests
  • is refused by the web clip extension

Marked moments, notes and meetings are not affected. You can also right-click an entry in the Activity list, or an app or domain in the Apps view, to mark it as private.

#Permissions

The state of Screen Recording, Accessibility, Microphone and Automation, with buttons to the matching System Settings panes. See install.

#Storage

Shows the disk space each kind of data takes, and sets how long files are kept.

DataDefaultChoices
Screenshots14 days7, 14, 30, 90 days, forever
Marked momentsforever1, 3, 6, 12 months, forever
Summary logsforever1, 3, 6, 12 months, forever

Retention deletes only image and log files, never the text in the database. A screenshot image is deleted only after its description exists. A shorter period that would delete files right away asks first.

Here you can also choose another data folder. It takes effect after “Restart Now”. Existing data is not moved: to keep it, quit Daily Recall, copy the old folder’s contents into the new folder, then start it.
