Settings › Prompts holds “About me” and six prompts. Pick a prompt in the “Prompt” menu, edit it, and use “Reset to Default” to go back. Changes apply to requests made afterwards. Existing descriptions, digests and summaries are not redone.

#About me

A few sentences about you and your work, for example “Work laptop. Engineering manager of a payments team; I also code.” When it is not empty, it is sent as a system message with every request: prompts 1 to 6 and the search question parse. “Test Connection” does not send it.

#Placeholders

Each placeholder is replaced before the request is sent. For prompts 2, 4, 5 and 6, placeholders missing from your text are appended after it.

#1 · Screenshot

PlaceholderReplaced by
{{time}}local capture time, e.g. 2026-10-27 14:05
{{window}}app, window title and URL
{{scope}}”one window” or “the whole screen”

#2 · Daily Summary

PlaceholderReplaced by
{{date}}the day and its range, e.g. Tue 27 Oct 2026 (04:00 – Wed 28 Oct 04:00)
{{log}}the merged log of the day (below)
{{app_totals}}one App 1h 12m line per app, longest first
{{marked}}the day’s marked moments, or none
{{meetings}}each meeting with its digest, or its notes if it has no digest
{{pages}}each clipped page with its digest
{{notes}}each note with its title and body

The log merges consecutive spans of the same window, leaves out spans shorter than 30 s, and interleaves screenshot descriptions, meetings, notes, clipped pages and absences:

09:00-09:58  Xcode  "AuthService.swift"
09:58-10:09  Google Chrome  "PR #12 - GitHub"  https://github.com/x/y/pull/12
10:05  [screen] Reviews PR #12 in GitHub. Comments on the auth change.
10:30-10:50  (idle)
11:30-11:55  [meeting] Sprint Review
    Topic: sprint review of the Atlas team.
    Decisions: ...
13:42  [page] Atlas rollout plan  https://wiki.example.com/atlas/rollout
    Rollout plan for Atlas in two waves.
14:05  [note] Clarify the migration with Anna

A meeting with a current digest appears as its [meeting] line followed by the digest. Its spans, screenshots and notes are left out, because the digest already covers them.

#Import and export

“Export…” writes “About me” and prompts 1 to 4 and 6 to a JSON file. A sheet lets you uncheck sections you don’t want to share. The file holds no base URL, model, API key or private rules. Prompt 5 is not part of the file.

{
  "format" : "daily-recall-prompts",
  "version" : 1,
  "aboutMe" : "Work laptop. Engineering manager of a payments team; I also code.",
  "prompts" : {
    "screenshot" : { "text" : "…" },
    "summary" : { "text" : "…", "thinking" : true },
    "marked" : { "text" : "…", "thinking" : true },
    "meeting" : { "text" : "…", "thinking" : true },
    "page" : { "text" : "…", "thinking" : true }
  }
}

“Import…” shows the same sheet. “About me” starts unchecked, so importing someone else’s prompts does not replace your context by accident. “Replace” overwrites only the checked sections. A file that is not JSON, has another format, a newer version or no sections is refused, and nothing changes.
